This repository contains scripts and data associated with the paper titled - "Growth rate dependent global DNA methylation patterns in bacteria", preprint available at - link. 

In this work, we analyze the methylome of diverse bacteria species under different environmental regimes, and ask how global methylation patterns change with changing environments. We use Oxford Nanopore long-read sequencing to quantify the methylome. The raw reads from nanopore data (in a POD5 format) are processed using dorado (link).
