This repository contains code and data for manuscript titled "Growth rate dependent global methylation patterns in bacteria", preprint available at - link. 

In this work, we analyze the methylome of diverse bacteria species under different environmental regimes, and ask how global methylation patterns change with changing environments. We use Oxford Nanopore long-read sequencing to quantify the methylome. The raw reads from nanopore data (in a POD5 format) are processed using dorado (link). The bash script to do that is named dorado_gpu.sh, which takes a POD5 file as an input and outputs a modified bam file containing all reads and predicted methylation states. To understand the methylome from this data, we first use minimap2 (link) to map these reads back to a reference genome, and second, modkit (link) to quantify the number of reads where each site was methylated and unmethylated. Both these steps are done using one combined bash script named aligned_bam.sh, which takes the modified bam file produced by dorado and converts it finally to a bedmethyl file, which is a table summarizing the methylation state of each site. All intermediate files are saved as illusrated in the script. The bedmethyl files are converted into a tsv format, and downstream analysis is performed using R.
